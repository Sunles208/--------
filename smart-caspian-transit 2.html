Цвет порта показывает риск сорвать стыковку: зелёный низкий, жёлтый повышенный, красный высокий. Пунктир — морской участок. Схема не в масштабе. Клик по линии маршрута выбирает его.

Прогноз задержки

Ожидаемая задержка в часах при отправке в выбранный день, маршрут через Астрахань. Рамка — лучший день, жирная подпись — выбранная дата отправки.

Цифровой коридор: pre-clearance

contract PreClearance {
  require(docs.complete);
  require(weight == declared);
  require(risk.score < 30);
  emit Cleared(cargo, RU_CUSTOMS);
  emit Cleared(cargo, IR_CUSTOMS);
  corridor.status = GREEN;
}

Демо-логика. В рабочей версии: Hyperledger Fabric или защищённые API между таможенными системами.
